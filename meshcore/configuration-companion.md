# Configuration d'un companion MeshCore

## Nommage d'un nœud compagnon
Rendez-vous dans Paramètres → Informations publiques, puis renommez votre nœud.
Nous recommandons : [FR83]-[Prénom-ou-Pseudo]
Exemple, le nœud compagnon de Paul : « FR83-Paul ».

## Paramètres Radio
Nous utilisons le préréglage « EU/UK (Narrow) ».
Réglages dans Paramètres → Paramètres radio.

| Paramètre | Valeur |
| --------- | ------ |
| Fréquence | 869.618 MHz |
| Bande passante | 62.5 kHz |
| Facteur de dispersion (SF) | 8 |
| Taux de codage (CR) | 8 |

## Paramètres Réseau
Dans Paramètres → Paramètres Réseau, appliquez les paramètres suivants :

| Paramètre | Valeur |
| --------- | ------ |
| Taille d'en-tête | 2 octets |
| Région par défaut | fr |
