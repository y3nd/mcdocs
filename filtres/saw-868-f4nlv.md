## Caractéristiques techniques
| Caractéristique | Valeur |
|-----------------|-------|
| Type de filtre | SAW (Surface Acoustic Wave) |
| Fréquence centrale | 869 MHz |
| Bande passante | 869 MHz ± 4 MHz |
| Perte d'insertion | 1.5-1.8 dB |
| Puissance maximale | 27 dBm |
| Atténuation hors bande | 30-40 dB |
| Connecteur A | u.FL (ou IPEX1) |
| Connecteur B | u.FL (ou IPEX1) |
| Lieu de fabrication | Var, France |

## Contenu de l'emballage
- Filtre SAW 868 MHz F4NLV avec connecteurs U.FL et adhésif double-face
- Câble u.FL <-> u.FL de 5 cm
