# Flash MeshCore
Pour flasher le firmware MeshCore, il suffit d'utiliser le [Web Flasher MeshCore](https://flasher.meshcore.io/) et de suivre les instructions.

:::warning
Assurez-vous d'installer le firmware correspondant à votre matériel. Si le firmware ne correspond pas à votre appareil, cela peut empêcher le démarrage de l'appareil
:::

:::warning
Il est recommandé de vérifier que le bootloader OTAFIX est installé avant de flasher le firmware MeshCore, car cela permet d'éviter les problèmes de mise à jour OTA à l'avenir.
:::

:::warning
Il peut y avoir des versions spécifiques avec des problèmes connus. La version actuellement recommandée pour les répéteurs est la `v1.15.0`
:::
