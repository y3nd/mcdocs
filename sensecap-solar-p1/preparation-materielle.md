# Préparation matérielle

:::warning
Certaines pièces métalliques comme la plaque qui supporte le boitier et l'antenne n'est pas ébavurée et peut présenter des bords tranchants. Il est recommandé de porter des gants de protection lors de la manipulation de ces éléments pour éviter les coupures.
:::

## Outils nécessaires
- Tournevis cruciforme de grande taille
- Set de pinces ou de clés pour le serrage des connecteurs SMA et type N
- [option] Ruban adhésif opaque pour couvrir les LEDs (type scotch d'électricien)
- [option] Ruban adhésif transparent pour protéger les étiquettes d'identification
- [option] Étiquettes pour indiquer le nom du répéteur et les informations de contact
- [option] Clé(s) dynamométrique(s) pour connecteurs SMA et type N

## Montage
1. Mettez dès à présent le boitier à charger.
2. Le montage du manuel indique d'utiliser le système de fixation à pivot afin d'orienter le panneau. Cependant celui-ci réhausse le panneau qui peut venir cacher l'antenne et ainsi réduire la portée du répéteur. De plus, cet élément réduit la rigidité de fixation du boitier. **Il est donc recommandé d'omettre la partie pivot (n°2 sur l'image) pour venir directement fixer le boitier à la plaque support d'antenne.**
2.1. Dans le cas où le pivot est conservé, placer le boitier dans la position la plus basse possible. Retirer entièrement le plastique de protection sur le pivot, celui-ci se dégrade rapidement.
3. Monter les fixations suivant s'il doit être fixé sur un poteau rond ou rectangulaire. L'élement n°5 ne doit être utilisé que pour les supports ronds, il peut être omis pour les supports rectangulaires.
4. Monter l'antenne type N sur l'emplacement le plus proche du boitier. Cela permettra de limiter l'effet du support (poteau/tronc..) sur l'antenne.
5. Il est recommandé d'indiquer le nom du répéteur et des informations de contact à l'aide d'étiquettes collées sur le boitier. Protéger ces étiquettes avec du ruban adhésif transparent fait pour l'extérieur. Un morceau de papier peut également être glissé à l'intérieur du boitier.
6. Les LEDs de l'appareil sont très lumineuses et peuvent être visibles de loin. Il est recommandé de les couvrir avec du ruban adhésif opaque type scotch d'électricien pour éviter d'attirer l'attention sur le répéteur.
7. Serrer fort les élements et mettre du frein filet sur les vis pour éviter qu'elles ne se desserrent avec les vibrations que peuvent provoquer le vent.
8. Ne pas serrer trop fort le connecteur SMA pour éviter d'endommager le boitier. Des clés dynamométriques sont disponibles pour ce type de connecteur et permettent de serrer à la bonne force (0.5 à 0.9 Nm).
