# GPS
Le SenseCAP Solar P1 **dans sa version Pro** est équipé d'un GPS multiconstellation (GNSS) Quectel L76K permettant de fournir la position du répéteur. Cette fonctionnalité peut être très utile pour localiser le répéteur et synchroniser la date et l'heure du système.

Il peut être activé avec la commande
```
gps on
```

:::info
Il est recommandé d'activer le GPS pour la synchronisation de l'heure du système, mais **cela augmente la consommation** du répéteur. Cette fonctionnalité peut être désactivée et l'heure mise à jour à manuellement via l'interface administrateur afin de réduire la consommation.
:::
